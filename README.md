# LED IT SOUND

Одностраничный сайт кавер-группы **LED IT SOUND** (Led Zeppelin tribute): главный экран, о группе, концерты, новости, соцсети и форма заявки.

Чистый HTML + CSS + немного JavaScript, без сборки и зависимостей.

## Структура

```
.
├── index.html        # разметка страницы
├── css/
│   └── styles.css    # стили, дизайн-токены в :root, адаптив (850 / 650 / 390 px)
├── js/
│   └── main.js       # мобильное меню и отправка заявки через mailto
└── images/           # фотографии, фоны и favicon
```

## Запуск локально

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python3 -m http.server 8000
# http://localhost:8000
```

## Публикация на GitHub Pages

1. Загрузите репозиторий на GitHub.
2. `Settings → Pages → Build and deployment → Deploy from a branch`.
3. Выберите ветку `main` и папку `/ (root)`.

## Что внутри

- Адаптивная вёрстка (CSS Grid / Flexbox), мобильное меню.
- Шрифты Bodoni Moda и Roboto Condensed подключаются с Google Fonts.
- Форма заявки открывает почтовую программу (`mailto:`), серверной части нет.
- Изображения подгружаются лениво (`loading="lazy"`), у них заданы `width`/`height`.

## Что стоит доработать

- Даты и площадки в блоке «Концерты» — пример оформления, замените на актуальные.
- Ссылки в блоке «Социальные сети» ведут на главные страницы VK, YouTube и Instagram — подставьте ссылки группы.
